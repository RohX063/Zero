# ZERO 2.5 R3.2 — UCI Telemetry Fix

This checkpoint fixes the UCI search-information stream without changing LMR, NMP, evaluation, TT logic, move ordering, or move generation.

## Added per-iteration `info` fields

- `depth`
- `seldepth`
- `score cp`
- `time` (milliseconds)
- `nodes`
- `nps`
- `hashfull` (UCI permille)

`seldepth` is tracked from the actual search ply, including quiescence-search visits. Search elapsed time starts at `beginSearch()` and NPS is computed from accumulated nodes and elapsed time.

## Output reliability

UCI handshake, `readyok`, iterative search `info`, and `bestmove` are explicitly flushed so GUI clients receive telemetry promptly.

## Scope guarantee

No search heuristic or chess decision rule was changed by this checkpoint. This is telemetry/observability infrastructure only.
